# Twemoji Country Flags

`TwemojiCountryFlags.woff2` is taken unchanged from the npm package
[country-flag-emoji-polyfill](https://github.com/talkjs/country-flag-emoji-polyfill) 0.1.10 by TalkJS:
a subset of [Twemoji Mozilla](https://github.com/mozilla/twemoji-colr) that holds only the flag emoji.
firc loads it for the flag code points alone (see `fonts.css`), since Windows has no flag glyphs and
shows the two letters instead.
